# Privacy and Data-Minimization Notes

This prototype is intentionally static and simulated.

## Do not collect in v1

- Government ID images
- Raw ID numbers
- Biometric data
- Liveness videos
- Exact birthdates
- Child names
- Guardian identity details
- Wallet keys
- Bank details
- Payment information

## Future verification concept

If real verification is explored later, a qualified third-party provider should handle document/liveness checks. Equity for Humanity should receive only minimal derived claims when lawful and necessary, such as:

- verification status
- verification method
- unique-human token
- age bracket / adult status
- verification timestamp
- next eligibility review month if needed

## Children/youth

The prototype uses only age brackets:

- under 16 / guardian-managed where lawful
- 16–17
- 18+

No child or guardian identity data is collected.

## Contribution and recycling credit

Recycled, unclaimed, and contributed-back benefits are displayed as participant contribution credit in the prototype. This is a recognition/impact concept only and creates no live payout, tax, legal, or financial claim.
